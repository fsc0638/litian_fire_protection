## 待辦（要在連得上主機的電腦上做，例如辦公室的 Windows）

1. **連上主機**：`ssh ubuntu@<主機IP>`。第一次連線時，主機 ED25519 指紋必須是 `SHA256:L/OSQXmOk2cL43VkqZoFZhBgT4uEaYIRj/7kSZq54eA`，相同才輸入 yes。
2. **讓 Mac（fsc0638）也能連**：連進主機後執行
   ```
   echo 'ssh-ed25519 AAAAC3NzaC1lZDI1NTE5AAAAIBJ/pEuWU/qYxB3UoJ2AA3WRa2IfRF9UKMar8vYi/EcM fsc0638-mac-claude-litian' >> ~/.ssh/authorized_keys
   ```
   Mac 那邊的私鑰在 `~/.ssh/litian_oracle`。不想讓那台 Mac 再連時，刪掉 `authorized_keys` 裡這一行即可。
3. **確認有沒有部署**：`git -C /opt/litian/repo log -1 --oneline` 應該是 `65a7728` 或更新的 commit。
   - 不是的話，代表 push 後**沒有**自動部署，要手動執行 `bash /opt/litian/repo/deploy/oracle/06_update_from_git.sh`。
   - 部署完成後執行 `curl http://127.0.0.1:8100/api/health`，再到工作台看下拉選單裡有沒有 14／30／60／90 天。
